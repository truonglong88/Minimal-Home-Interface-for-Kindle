# Install KOReader

Minimal Home is a KOReader plugin, so KOReader has to be on the device first.

## Kindle

A Kindle only runs KOReader after a **jailbreak**. Which jailbreak works depends
on the model and the firmware version, and this changes over time, so follow the
up-to-date guides rather than a copy here:

1. **Jailbreak** – [kindlemodding.org](https://kindlemodding.org/) lists the
   current method for each firmware. Check your firmware first:
   *Settings → Device Options → Device Info*.
2. **Install KUAL and MRPI** (the launcher and package installer) – also on
   kindlemodding.org.
3. **Install KOReader** – [KOReader wiki: Installation on Kindle devices](https://github.com/koreader/koreader/wiki/Installation-on-Kindle-devices).
   Download the Kindle package from [KOReader releases](https://github.com/koreader/koreader/releases).
4. Start KOReader from KUAL.

> Jailbreaking is at your own risk. Keep Wi-Fi off / airplane mode on while
> following a jailbreak guide, as the guides advise, so the Kindle doesn't
> update itself in the middle.

## Other devices

Kobo, PocketBook, Android and others: see the
[KOReader wiki](https://github.com/koreader/koreader/wiki) for your device.

Then [install Minimal Home](install-plugin.md).
